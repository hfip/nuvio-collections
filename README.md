# Nuvio Collections

Ready-to-import **Nuvio** collection profiles with Arabic titles, descriptions and posters.

## Files

| File | Description |
|---|---|
| `_ser.json` | Series collection profile |
| `nuvio-collections-profile-1-2026-04-24.json` | Full profile export (collections + artwork metadata) |

## How to use

1. Download the JSON file you want.
2. In Nuvio, open **Collections → Import** and pick the file.
3. The collections appear with their Arabic names and posters.

## Notes

- The JSON follows Nuvio's collection profile format; keep the structure intact when editing.
- Artwork URLs point to public image hosts — replace them with your own if they stop resolving.
